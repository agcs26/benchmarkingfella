How to Benchmark Devices

Choose Your Option

Option 1: For regular laptops or PCs that won't handle games or resource-demanding software. Also use this if end users are unlikely to run such software.

Option 2: For powerful devices capable of running demanding applications and games.

Important Notes

  • If you benchmark a laptop, always connect its charger and change charging settings to the Performance mode while plugged in.
  • Do not forget to grab results ID! This is your last part of URL when you open results in web browser.

Option 1: Basic Benchmarking

  1. Copy PCMark 10 folder to the device.
  2. Install PCMark.
  3. Launch it and click RUN to run a basic benchmark. It will take some time.
  4. After the benchmark is done, go to the Final steps section.

Option 2: Comprehensive Benchmarking

  1. Copy PCMark 10 folder and 3DMark archive to the device.
  2. Install PCMark.
  3. Unzip and install 3DMark.
  4. Launch PCMark and click RUN to run a basic benchmark. It will take some time. Wait until it finishes.
  5. Launch 3DMark and run the RECOMMENDED benchmark for this device. Here is what each available benchmark in this version means:
    • Steel Nomad - heavy rasterized benchmark for current hardware (gaming PCs)
    • Steel Nomad Light - light rasterized gaming, lightweght PCs
    • Solar Bay Extreme - ray-traced gaming for lightweight systems and laptops with integrated graphics
    • Solar Bay - light ray-traced gaming
    • Time Spy - for gaming PCs with DirectX 12 support
    • Fire Strike - for older or mid-range gaming PCs using DirectX 11
    • Night Raid - for laptops, tablets, and integrated graphics
  6. After the benchmark is done, go to the Final steps section.

Final Steps

  1. Open BENCHMARKINGFELLA, select 'Performance Card Generator' page and fill in the results you got from the benchmarks you ran. Do not forget to include the results ID!
  2. Click "Print / Save as PDF" button, select the proper printer and make sure the 5x7" paper is selected in the printing settings.
  3. Print the Performance card on the back of your device's price card.
  4. Delete all the installed software and installation files from the device.
